# Aron Rop — Developer Portfolio

Personal developer portfolio for **Aron Rop**, a Full-Stack Software Engineer
specializing in Python, Flask, SQL, responsive frontend engineering and
production-oriented web development.

## Overview

The portfolio is intentionally built without a frontend framework.

The goal is to demonstrate:

- Semantic HTML
- Accessible interfaces
- Responsive CSS
- Modern JavaScript
- Flask backend architecture
- SEO fundamentals
- Production deployment
- Git-based development workflow
- Performance-conscious engineering

## Technology

### Backend

- Python
- Flask
- Jinja2

### Frontend

- HTML5
- CSS3
- JavaScript ES6+

### Deployment

- Vercel
- GitHub
